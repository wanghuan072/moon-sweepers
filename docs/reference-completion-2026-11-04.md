新增目录和价格保存在纯JSON：`exploration-directory.json`、`structure-prices.json`。生成逻辑在 `complete-reference.mjs` 和 `complete-guides.mjs`，由 `npm run data` 统一重建。

主要参考 [Wikily](https://wikily.gg/moon-sweepers/) 的工具、容器、宇航服、升级矩阵、材料、经济、建筑与机制栏目；自动化交叉参考 [MoonSweepersWiki](https://www.moonsweeperswiki.com/automation/)。官方配置与语言来自 [Steam App Details](https://store.steampowered.com/api/appdetails?appids=5335510&l=english&cc=us)，元数据快照保存在 `scripts/data/steam-product-snapshot.json`。各页面表格仍保留直接来源链接。

本轮36张工具和升级图片与之前19张设备图片合计55张，另有15张官方Steam截图；全部维持本地开发预览范围。恢复新增图片运行 `python scripts/data/import-wiki-content-media.py`，脚本可直接使用已提交的来源清单，不依赖浏览器临时缓存。生产排除规则与API白名单已覆盖新图片。

目录超过30行时提供独立搜索和滚动区域，避免把195条记录堆成无法使用的长页面。材料收入计算器单独处理1.28倍最高销售加成、个人区域奖励与团队区域基础奖励；结果不是按时间计算的利润。最低/推荐PC配置不构成帧率承诺，社区参数未声称独立游戏内实测。
